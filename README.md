# Crewd Homebrew Tap

Official Homebrew tap for [Crewd](https://crewd.dev), the package manager for prompt-defined AI agents, skills, and teams across Claude Code, Cursor, and Gemini CLI.

---

## Installation

To install `crewd`:

```bash
brew install crewdhq/tap/crewd
```

Or tap the repository first and install:

```bash
brew tap crewdhq/tap
brew install crewd
```

---

## Updating

To update `crewd` to the latest release:

```bash
brew update
brew upgrade crewd
```
